# src/ddr3_memory_interface/

Gowin DDR3 Memory Interface IP, the encrypted netlist from Sipeed's
[TangPrimer-20K-example](https://github.com/sipeed/TangPrimer-20K-example)
`DDR-test/LicheeTang20K_DDR_Test/src/ddr3_memory_interface/` (commit
`e469df4`), generated by Gowin 1.9.8.05 (1:4, 400 MHz, x16, 14 row bits).
That repository is BSD-3-Clause (`LICENSE` here); the netlist itself is
Gowin's generated output.

Why this one and not a fresh one: Gowin 1.9.12.04 only generates the newer
`ddr3_1_4code_hs` core for 1:4, and that never calibrated on this board in
any configuration tried, even inside Sipeed's own test design; this 1.9.8
`ddr3_1_4` netlist calibrates there. It needs 8 BSRAM, which is why main
memory's language-card RAM moved into DDR3 (src/aux_ram.v).

`sim/models/ddr3_model.v` stands in for it in simulation.
