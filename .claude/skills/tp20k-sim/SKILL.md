# Simulate Tang Primer 20K designs

Tools (on user PATH; call by full path in case the shell predates it):

```bash
IVERILOG=/c/iverilog/bin/iverilog
VVP=/c/iverilog/bin/vvp
GTKWAVE=/c/iverilog/gtkwave/bin/gtkwave
GW_PRIM=/c/Gowin/Gowin_V1.9.12.04_x64/IDE/simlib/gw2a/prim_sim.v   # Gowin primitive models
```

Gowin EDA ships no simulator; Icarus 12 is installed.

## Layout

Testbenches go in `sim/` next to `src/` (see `tp20k-build`): `sim/tb_<module>.v`.
Never add `sim/` files to `build.tcl`.

## Self-checking testbench template

```verilog
`timescale 1ns/1ps
module tb_top;
  reg clk = 0;
  always #18.518 clk = ~clk;            // 27 MHz board clock (H11)
  wire [5:0] led;

  top #(.DIV(4)) dut (.clk(clk), .led(led));   // shrink counters via parameters

  initial begin
    $dumpfile("sim/tb_top.vcd");
    $dumpvars(0, tb_top);
    repeat (20) @(posedge clk);
    if (led !== 6'b000011) $fatal(1, "FAIL: led=%b", led);
    $display("PASS");
    $finish;
  end

  initial begin #1_000_000; $fatal(1, "FAIL: timeout"); end   // watchdog
endmodule
```

Rules:
- Make the DUT's slow counters a `parameter` so the testbench can shrink them;
  never simulate a 2^25 blink divider at full size.
- Compare with `!==`/`===` so X/Z fail instead of passing.
- Pass/fail is the exit code: `$fatal(1, …)` → exit 1, `$finish` → exit 0.
  Always print `PASS` on success.
- Give regs an initial value or a reset; the sim starts at X while the FPGA
  powers up at 0 (`reg [7:0] r = 0;` is synthesized as the init value by Gowin).

## Run

```bash
cd <proj>
"$IVERILOG" -g2012 -Wall -Wno-timescale -o sim/tb_top.vvp sim/tb_top.v src/*.v && "$VVP" -n sim/tb_top.vvp
```

- `-g2012` enables SystemVerilog-ish features; `-I src` for `` `include``.
- `vvp -n` = exit at `$stop` instead of an interactive prompt (don't hang the shell).
- Exit 0 + `PASS` = passed. Report failures with the `$display` line.

### With Gowin primitives (rPLL, DPB/SDPB BSRAM, IDDR, ODDR, OSER10, ...)

Add the library and silence its noise:

```bash
"$IVERILOG" -g2012 -o sim/tb.vvp sim/tb_top.v src/*.v "$GW_PRIM" 2>&1 | grep -v "prim_sim.v" ; "$VVP" -n sim/tb.vvp
```

- `prim_sim.v` is large (~5 s compile); its `@* found no sensitivities` warnings are harmless.
- **rPLL LOCK takes 50–200 µs of sim time** (the model counts real lock time).
  Wait on `@(posedge lock)` with a watchdog > 250 µs, don't assert at a fixed early time.
- Set `.DEVICE("GW2A-18C")` on rPLL; the model defaults to GW2A-55.
- IP generated by the IDE (e.g. `src/gowin_rpll/gowin_rpll.v`) instantiates these
  primitives, so the same command covers it. DDR3 controller IP is encrypted —
  it can't be simulated with Icarus.

## Waveforms

```bash
"$GTKWAVE" sim/tb_top.vcd &        # GUI, opens on the user's desktop
```

Save the signal layout from GTKWave as `sim/tb_top.gtkw` and reopen with
`"$GTKWAVE" sim/tb_top.gtkw`. You can't see the GUI; to inspect values yourself,
`$display`/`$monitor` in the testbench instead of reading the VCD.

Large dumps: limit scope (`$dumpvars(1, tb_top.dut)`) or use FST
(`vvp -n sim/tb.vvp -fst`, with `$dumpfile("sim/tb.fst")`).

## Gotchas

- Icarus doesn't support all SystemVerilog (no classes, limited interfaces/
  assertions). For heavy SV or long sims (CPU cores), suggest Verilator.
- VHDL: Icarus can't; GHDL would be needed (not installed).
- Delays (`#`) are ignored by synthesis; only use them in `sim/`.
